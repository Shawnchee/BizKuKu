## 🚩 Project Overview

### Problem Statement
- **Lack of Formal Business Identity**
- **Limited Access to Financial Resources for Growth**
- *Example*: He sells Nasi Lemak by the roadside, taking payment in cash and personal QR.

### Solution
**Onboard:**
- SSM Registration
- Open Merchant Bank Accounts
- Setup Digital Payment

**Manage:**
- OpenFinance Dashboard
- Financial Health Scoring Report Generation

**Scale:**
- Loan and Funding Recommendations
- Online Business Adoption

---

## 🎯 Mission

Empowering MSMEs to onboard, manage, and grow with digital tools, financial access, and business intelligence.

## ✨ Key Features

### 🚀 Onboarding for Growth
- **SSM Registration**: Formalize your business identity in minutes
- **Merchant Bank Account Opening**: Get access to business banking
- **Digital Payment Setup**: Accept payments via QR, e-wallets, and more

### 📊 Financial Management
- **OpenFinance Dashboard**: Unified view of all your business accounts
- **Financial Health Scoring**: Automated reports to track and improve your business health

### 📈 Growth & Scaling
- **Loan & Funding Recommendations**: AI-powered matching to relevant grants, loans, and subsidies
- **Online Business Adoption**: Connect to Shopee, Lazada, TikTok Shop, Facebook Shop, GrabFood, Foodpanda, and more
- **One-Click Applications**: Streamlined process for business support programs

### 🧑‍💼 MSME-Focused Support
- Multi-language support (Bahasa Malaysia, English)
- Video tutorials, WhatsApp & phone support
- Simple guides for product photography, pricing, shipping, and more

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Shawnchee/BizKuKu.git
cd bizkuku
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

5. Setup Backend
```sh
cd backend
pip install -r requirements.txt
```

6. Run the Backend
```sh
uvicorn main:app --reload
```
The backend will be available at http://localhost:8000
